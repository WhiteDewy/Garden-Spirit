## 一、解盘总纲：逐层剥开一张盘

### 1.1 从问题出发，不是从盘出发

单项解读时直奔主题领域，不做全盘罗列。

```
问事业 → 从6宫（日常技能）和10宫（事业名望）切入
问感情 → 从金星（魅力）、火星（行动）、月亮（依赖）切入
问财运 → 从2/8/11宫切入
```

**"我们围绕的看盘的逻辑是公主星。"**

### 1.2 掌宫优于落宫

> "始终还是公信。掌宫优于落宫，落宫只是舞台。"

星的意义首先来自**它管哪个宫**（宫主），其次才是**它落在哪个宫**（舞台）。

例：火星管10宫 = 它就是事业象征星，不管它落陷在哪儿，它首先是事业星。落宫只决定它"在哪个场地上演这出戏"。

### 1.3 星体状态 = 能不能扛得住

找到宫主星后，第一件事判断它自己行不行：
- 尊贵够不够（入庙/入旺 vs 落陷/失势）
- 失时与否（日生盘的火星落阴性星座 = 失时）
- 被刑冲多少

> "火星天秤落陷 + 日生盘失时 → 不太行，不是特别好"

### 1.4 "谁在帮它"链式追踪（核心技法）

**当宫主星自己弱的时候，帮它的星才是实际显化的。**

```
10宫主火星(落陷,弱) ← 水星接纳(援军)
                          ↓
                    水星 = 2R飞11
                          ↓
                    管公司财 + 大平台
                          ↓
                    实际职业 = 财务高管
```

> "你做的事情没有直接在火星上得到体现，都在水星上得到体现，水星反而成了你的第一职业象征星。"

**宫主星是剧本，帮它的星是主演。**

### 1.5 交感的行业映射

交感宫群（一星多宫主飞入同一宫）→ 过去从事过的行业通常能对上。

```
4宫(房产) + 9宫(远方) + 10宫(事业) 全飞3宫(交通)
→ 做过房地产 ✅ → 做过汽车 ✅ → 做过商业 ✅
```

然后用"验前事"验证：对应的行运时段应该发生过对应的事。

## 二、飞星组合的底层逻辑

### 2.1 三层叠加模型

```
第一层：源宫 → 目标宫 的领域传导
  源宫的"多顶帽子"带上 → 目标宫的舞台上演绎

第二层：转宫视角（相对宫位）
  目标宫是源宫的第几宫 → 决定这段关系的基本色调

第三层：星体吉凶调制（jin/ke）
  同样的结构，领主强=输出建设性，领主弱=输出破坏性
```

### 2.2 每个宫的"多顶帽子"

一个宫不止一个意思。飞星时原宫的每一顶帽子都会在目标宫落地。

以4宫为例，至少六顶帽子：
| 帽子 | 4飞X的含义 |
|------|----------|
| 房产/土地/不动产 | 房子→目标宫领域（出租、合租、置业） |
| 父亲 | 父亲在目标宫领域的表现 |
| 原生家庭/家族根基 | 家族→目标宫 |
| 内心安全感/情绪地基 | 情绪→目标宫 |
| 祖产/继承 | 祖产→目标宫 |
| 晚年归宿 | 晚年→目标宫 |

### 2.3 转宫视角

**目标宫在源宫的"第几宫"，决定这段关系的基本色调。**

| 目标宫是源宫的 | 底色 | 例子 |
|-------------|------|------|
| 第2宫 | 钱/价值 | 4飞5→父亲舍得给恋人花钱(or父亲好赌) |
| 第5宫 | 快乐/创造力 | 4飞8→家族兴旺(or父亲投机失利) |
| 第7宫 | 对手/伴侣 | 4飞10→父母关系(or父亲事业地位) |
| 第8宫 | 暗面/危机/转化 | "4之8"=登神梯or心魔关 |
| 第12宫 | 消融/业力 | 4飞3→漂泊or手足争家产 |

**每个"X之8"条目同时包含正负两面——第8宫本质是吉凶两极的。**

### 2.4 得吉/受克 = 同一个剧本的两种结局

```
飞星结构 = 剧本大纲（谁在谁的舞台上干什么）
jin/ke   = 这个剧本导演拍得好不好

得吉 → 获得、利于、促成、带来帮助
受克 → 破坏、受损、拖累、带来麻烦
```

### 2.5 同宫反馈（自循环）

源宫=目标宫时形成自我反馈闭环：
- 9飞9"智慧导师"：深造→深造，正反馈
- 12飞12"玄学缘分"：业力→业力，可深可沉
- 8飞8"黑色吸引力"：暗面→暗面，极端魅力和极端危险并存

### 2.6 多帽并行，不互斥

同一个飞星可以同时激活多条含义线，吉线和凶线也可以同浮（吉凶两论）。

## 三、金火月·感情解读体系

### 3.1 金星 = 魅力发射器

| 维度 | 内容 |
|------|------|
| 落座 | 怎么展现魅力（白羊=打直球、金牛=物质滋养、双子=陪玩陪聊...） |
| 落宫 | 在哪个领域最吸人（金1=外形气质、金2=赚钱消费时、金3=说话声音...） |
| 接纳金星的星体 | 谁在给你魅力加分 |
| 被金星接纳的星体 | 你的魅力能辐射到哪些领域 |
| 刑冲金星 | 什么在败坏你的魅力 |
| 凶星互融金星 | 魅力表达比较扭曲，但不一定弱 |

**男女盘区别**：女盘金星=你要用它去吸引人；男盘金星=他会被什么类型的女性气质吸引。

### 3.2 火星 = 行动引擎

| 维度 | 内容 |
|------|------|
| 落座 | 怎么行动/追求 |
| 落宫 | 在哪个领域有胜负欲 |
| 接纳火星的星体 | 谁在帮你赢 |
| 被火星接纳的星体 | 你在哪个领域自然能赢（如火星接纳5宫主→谈恋爱对方容易服你软） |
| 刑冲火星 | 什么打断你的行动力 |

**男女盘区别**：男盘火星=用它去征服；女盘火星=被什么男性气质折服。

### 3.3 月亮 = 依赖感核心

> "你想让一个人喜欢你，看金星火星没问题。你想让这个人黏着你非你不可，你就得看他的月亮。"

| 维度 | 内容 |
|------|------|
| 落座 | 怎么获得情绪满足（土象=物质安全感、水象=情感滋养、风象=信息交流、火象=被认可夸赞） |
| 落宫 | 在哪里真正感到满足（月7=黏伴侣、月11=离不开朋友、月8=躲角落、月12=定期闭关） |
| 接纳月亮的星体 | 谁在给你情绪安全感 |
| 被月亮接纳的星体 | 你会天然去照顾/滋养谁 |
| 刑冲月亮 | 什么扰乱你情绪 |

**月亮不分男女——依赖感机制相同。**

### 3.4 感情解读的"海王公式"

1. 找到对方的月亮落宫 → 在那个领域持续给满足
2. 找到对方月亮接纳的星体 → 扮演被那个星体代表的角色
3. 找到对方金星落宫 → 在那个领域展现你自己的魅力
4. 通过行运找时机 → 对方5宫主/7宫主被引动时出手

> "懂星盘的人谈不好恋爱，白学了。"

## 四、行星函数 × 宫位变量推导法

### 4.1 核心公式

```
行星核心动词 × 宫位领域名词 × 得吉/受克副词
```

### 4.2 七行星核心函数

| 行星 | 核心动词 | 落Y宫 = |
|------|---------|--------|
| 太阳 | 自我意志要在这被看见 | 必须在这个领域发光，否则不甘心 |
| 月亮 | 情绪要在这获得滋养 | 在这个领域找安全感，黏在这就觉得安心 |
| 水星 | 脑子在这运转 | 信息在这流动，想和说都围着这个领域转 |
| 金星 | 魅力在这展现 | 在这个领域释放吸引力的方式 |
| 火星 | 胜负欲在这被激发 | 在这个领域争、抢、干、不服输 |
| 木星 | 扩张在这里发生 | 在这个领域容易膨胀、也容易遇到贵人 |
| 土星 | 恐惧和责任在这收紧 | 在这个领域焦虑、但咬牙撑住后最能成长 |

### 4.3 推导示例

**金1 → 水1**：
> 金1 = 魅力×自我 → "你什么额外的事都不用做，站那儿就有魅力"
> 水1 = 思维×自我 → "脑子就是你的名片，想到就说，嘴可能比脑子快半拍"

**金2 → 水2**：
> 金2 = 魅力×价值 → "赚钱消费时最有魅力"
> 水2 = 思维×价值 → "脑子围着钱转，对数字敏感，靠信息差和口才变现"

**金12 → 火12**：
> 金12 = 魅力×玄学 → "魅力在玄学/艺术/身心灵领域释放"
> 火12 = 胜负欲×暗处 → "竞争是暗处发生的——自己跟自己较劲、暗中超越"

### 4.4 与手写YAML的区别

| 方式 | 手写YAML（planet_in_house.yaml） | 公式推导 |
|------|--------------------------------|---------|
| 条数 | 120条独立手写 | 7个函数 × 12个宫域 + 调制规则 |
| 一致性 | 写的人不同风格不同 | 统一公式，风格一致 |
| 扩展性 | 新增行星要写12条 | 新增行星只加1条核心函数 |
| 可解释性 | 背出来的 | 推导出来的，每句有逻辑链 |

## 五、咨询伦理

### 5.1 飞星只代表过程，不代表最终结果

> "飞星永远只代表在这个事物的过程当中可能是好的或坏的，但它并不能代表最终的结果。"

### 5.2 给安慰不给绝望

> "碰到十公主状态不好的人——你不能跟他说追求功名没结果。你要告诉他，社会身份不是人生最重要的事。"

> "人没有吃不了的苦，只有享不了的福。要给人找出路，不是添堵。"

### 5.3 把抽象的"凶"变成具体可操作的"注意什么"

```
不说："你火星大运必有灾"
而说："火星大运时注意身体炎症、呼吸道喉咙四肢，尽量少出门避免磕碰"
```

### 5.4 碰到全盘很苦的人

> "挑他星盘当中哪些星可能比较好，对应法达的年份，告诉他这几年你会顺一点。人需要有期待。"

## 六、解盘实操流程（单项问题）

```
① 确定问题领域 → 锁定对应的宫主星
    职业=6/10宫主  感情=5/7宫主+金火月  财=2/8/11宫主

② 读宫主星自身状态
    尊贵? 失时? 多少刑冲? → "这颗星自己行不行"

③ 找援军
    谁接纳它? 谁跟它互溶? 谁给它吉相?
    → 援军的掌宫+落宫 = 实际显化的领域

④ 找压力源
    谁刑冲它? 被什么凶星互溶接纳?
    → 压力来自哪个领域、什么人

⑤ 交感映射
    一星多宫主都飞哪? → 哪些领域被串联了
    → 这个人过去做过什么行业/经历过什么事

⑥ 验前事
    对应的行运时段是否发生过对应的事
    → 验证本命结构解读是否正确

⑦ 给出路
    不能说"你这不行" → 说"这条路费力，但是援军在帮你"
    抽象的凶 → 具体可操作的注意事项
```

## 七、与 Garden-Spirit 系统的映射

| 梦老师技法 | 系统现状 | 待建 |
|----------|---------|------|
| 从问题定宫主星 | Strategy YAML ✅ | - |
| 掌宫优于落宫 | house_rulers() ✅ | - |
| 星体状态 | dignity_total() + _quality() ✅ | - |
| 链式追踪 | 互溶接纳检测 ✅ | **缺：自动构建支持图谱** |
| 交感映射 | detect_synapsis() ✅ | **缺：宫群→行业推导** |
| 验前事 | 法达+行运计算 ✅ | **缺：自动验证** |
| 金火月感情 | RuleEngine 原子事实 ✅ | **缺：跨星体合成解读** |
| 飞星多帽 | dispositor_rules.yaml ✅ | **缺：帽子清单文档** |
| 转宫底色 | YAML隐式含了部分 | **缺：系统化转宫规则表** |
| 给出路 | 证据卡 action 段 ✅ | **需丰富具体建议模板** |
| 咨询伦理护栏 | 无 | **需写入 LLM prompt** |
