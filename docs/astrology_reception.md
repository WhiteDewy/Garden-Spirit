# 接纳 / 互溶 / 末度 技法规范

> 状态：v1 技术规范（2026-08-03，随开发维护）
> 理论来源：传统占星（Lilly / Hellenistic 体系）+ 项目内规则评审
> 配套实现：`domain/astrology/knowledge/reception.py` · `reception.yaml`
> 测试：`tests/unit/test_reception_engine.py`（以真实盘为黄金断言）

---

## 1. 术语与分层

| 术语 | 定义 | 前提 |
|------|------|------|
| **互溶（Mutual Reception）** | A 落在 B 的尊贵星座 **且** B 落在 A 的尊贵星座（双向） | 仅凭尊严成立，**不需要相位** |
| **接纳（Acceptance）** | A 落在 B 的尊贵星座内（单向），且 A、B 之间有主相位 | 尊严 + 相位，二者缺一不可 |
| ~~潜在接纳~~ | ~~尊严成立、无相位~~ | **已废弃**：单向尊严无相位不构成接纳关系，不产出、不解读 |
| **末度（宫头）** | 行星位于某宫末几度、逼近下一宫宫头 | 阈值 3°/5°；0-1° 视为合宫头 |
| **末度（星座临界）** | 行星位于星座末度（29° 附近），携带下一星座气息 | anaretic / 临界 |

**互溶 vs 接纳的关键区别**：
- 互溶靠"双向尊严"自己形成绑定，相位只增强它，不决定它。
- 接纳靠"相位"激活——没有相位，单向尊严只是静态事实，不是一段关系。

## 2. 互溶（Mutual Reception）

### 2.1 判定

```
对 (A, B)：
  d_AB = B 在 A 所在星座的尊贵集   # B 在 A 的庙/旺/三分/界/面
  d_BA = A 在 B 所在星座的尊贵集
  两方向都通过严格度检验 → 互溶成立
强度 = 两方向"最强尊贵"中较弱的一方
```

### 2.2 严格度（可配置，`reception.yaml → mutual_reception.strictness`）

| 档位 | 规则 | 对应流派 |
|------|------|---------|
| `lenient` | 任一尊贵单一即可 | Hellenistic 宽松派 |
| `standard` | **庙/旺 单一即可；三分/界/面 需同方向"有其二"**（同方向至少两项尊贵确认） | 严格派（本项目的默认） |
| `strict` | 仅 庙/旺 构成互溶 | Lilly 最严立场 |

> 三分/界/面"有其二"的含义：若某一方向的最强尊贵是弱档（三分/界/面），
> 该方向必须同时拥有 ≥2 项来自 {三分, 界, 面} 的尊贵确认，才可信。

### 2.3 强度排序

庙（4）> 旺（3）> 三分（2）> 界（1）> 面（0）。取弱方。

### 2.4 三分主取法（可配置，`reception.yaml → triplicity.mode`）

| 模式 | 规则 | 说明 |
|------|------|------|
| `all`（默认） | 三分三主都算（日/夜/参予主） | 项目中默认，如"木星接纳月亮"（风象参予主） |
| `sect` | 仅按昼夜取一主 | 与 DignityEngine 一致（严格派） |

三分主取法是**流派选择**，不是对错问题；接纳/互溶引擎与尊贵引擎可各自按流派配置。

## 3. 接纳（Acceptance）

### 3.1 判定

```
对 (A, B)：
  A 落在 B 的尊贵星座内（单向）   # B 是接纳方（acceptor）
  且 A、B 之间有主相位（activate）  # conjunction/opposition/trine/square/sextile
  且该方向的尊贵满足严格度（与互溶同规则，见 §2.2）
  → 激活接纳，B 接纳 A
无相位或仅次要相位（半刑/八分/梅花等） → 不构成接纳（废弃"潜在接纳"）
非庙/旺时，单个三分/界/面力度不够，需"有其二"（≥2 项弱尊贵）。
```

### 3.2 相位性质决定"顺逆"

| 相位性质 | 含义 | 示例 |
|---------|------|------|
| 和谐（三合/六合） | 接纳顺畅，对方"愿意且舒服地"成就你 | 木星（7R）三分接纳月亮 + 六合相位 |
| 动态（刑/冲/合） | 被接纳但关系紧张/强制 | 火星三分接纳太阳 + 刑相位 |
| 中性 | 视具体情况 | — |

**接纳不抵消刑冲**：接纳让凶相"被接受、可商榷"，但不消除凶相本身。

### 3.3 与互溶的关系

已成互溶的 (A, B) 不再重复计入接纳（互溶是更强的绑定，覆盖之）。

### 3.4 参与星体范围（三王星与虚点排除）

**三王星（天王/海王/冥王）与虚点（节点/莉莉丝/凯龙）不参与互溶与接纳，只做相位与落宫叠加。**

- **世代性**：三王星星座落座是整代人共享的（天王 84 年、海王 165 年、冥王 248 年一周），
  "天王接纳土星"对 1988–1996 年出生者全部成立——世代共同点无个体解读意义。
- **个体作用保留在相位与落宫**：三王星的宫位与对内行星的相位完全个体，是它们真正起作用处。
- **虚点非行星**：节点/莉莉丝/凯龙是空间点，更不参与。
- **不影响单星尊贵**：三王星入庙（如冥王天蝎）作为"该星自身力量"仍可计算——那是尊贵强度，
  不是互溶接纳。二者是不同的技法令牌。
- 附带效果：排除后，现代制"土星↔天王"类互溶伪影自动消失。

配置：`reception.yaml → excluded_planets`（一行可改，不锁死流派）。

## 4. 末度规则（两个独立技法，必须分开判定）

### 4.1 宫头末度（行星近下一宫宫头）

- **技法**：行星落某宫末几度、逼近下一宫宫头 → 其影响进入下一宫。
- **表述**：主影响下一宫 + 保留本宫残余（**双宫都算，近的为主**），不是"完全归下一宫"。
- **阈值**：末 5°（严格派用 3°）；**0-1° 视为合宫头，直接计入下一宫**。
- 实例（夏天盘）：火星双子 23.3°，2宫头双子 23.5°（距 0.2°）→ 主影响 2 宫（财帛）。

### 4.2 星座末度（行星近下一星座，29° 附近）

- **技法**：行星落星座最后几度，携带即将交接的下一星座气质（anaretic）。
- 与宫头末度**互不干扰**：判定时先分清是"宫头末度"还是"星座末度"，两者阈值与语义不同。
- 实例（夏天盘）：太阳双鱼 29.9° → 星座临界（"灵性即将交接给白羊行动"），
  但**非宫头末度**（太阳落 11 宫中部，离 12 宫头很远）。

### 4.3 规则冲突防范

一星若同时满足两者（如某星 29° 且近宫头），分别评估，不互相覆盖。

## 5. 宫内星 = 过程，宫主星 = 结果 + 域激活

### 5.1 技法

- **宫内星** = 该人生领域的过程（日复一日如何展开）。
- **宫主星** = 该领域的结果（最终以什么形态落地）。

### 5.2 域激活（咨询中的处理）

一个宫位领域是**一组可能的生活形式（开放集）**，不是一个"事件"。
当接纳/互溶经由某宫主星发生（如 7R 木星接纳月亮），该接纳的激活取决于该宫领域是否在现实中显化：

- 未婚 → "伴侣"通道休眠，但"合伙人/长期客户/导师带教/签约合作"通道可能激活。
- **处理规则**：
  1. 不锁定单一事件（不说"你会在婚姻中得到滋养"）。
  2. 给开放集："当 7 宫领域以任何一对一关系出现时（伴侣 / 合伙 / 关键客户…），会激活这条接纳"。
  3. 结合 宫主星=结果："这类关系的'结果'落在 3 宫（沟通/学习/传播型关系）"。
  4. 不预言"一定会发生"，只描述"发生时以什么形态、带来什么"。

> 这与前瞻盲测原则一致：未显化领域无法事后验证，解读给的是"通道结构"，
> 由用户在现实中认领哪些通道是活的。

## 6. 黄金测试断言（夏天盘 · 阿卡比特）

> 以下断言基于 `triplicity.mode: "all"`（三分三主都算，日/夜/参予主全计）。
> 若切 `"sect"`（按昼夜取一主，与 DignityEngine 一致），火星/木星对太阳/月亮
> 的三分接纳不成立（日生盘分别取金星/土星为水象/风象三分主），需相应调整断言。
> 三分取法本身是可配置流派选择，不是对错问题（见 §2.4）。
> "十度" = 面（Chaldean decan，每宫 10° 一档）。尊贵以**完整尊贵集**呈现（庙+三分 / 三分+十度）。

| 断言 | 结构 | 结果 |
|------|------|------|
| 太阳 ↔ 木星 互溶 | 太阳（庙+三分）互溶木星（庙）· 三合 | ✅ 最强档 |
| 水星 ↔ 火星 互溶 | 水星（庙+三分）互溶火星（庙）· 六合 | ✅ 最强档（六合偏差 6.8° ≤ 容差 7°，主流做法） |
| 火星 → 接纳太阳 | 刑接纳 · 三分+十度 | ✅ 激活·动态（被接纳但紧张） |
| 木星 → 接纳月亮 | 六合接纳 · 三分+十度 | ✅ 激活·和谐（顺畅滋养） |
| 土星 → 接纳木星 | 冲接纳 · 三分+十度 | ✅ 激活·动态（木土冲的接纳版） |
| 太阳 → 接纳水星 | 太阳旺（白羊）接纳水星，无激活相位 | ❌ 不构成接纳（无相位） |
| 月亮 → 接纳太阳 | 仅单个三分（六合相位） | ❌ 单个弱尊贵力度不够（有其二规则） |
| 太阳 → 接纳火星 | 仅单个十度（刑相位） | ❌ 同上 |
