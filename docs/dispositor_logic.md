## 1. 飞星不是"搬家"，是"借力"

宫主星飞入某宫 = 把所掌宫位的力量带到该宫。得吉=带来帮助，受克=带来麻烦。

不是简单的"火星在8宫所以你有攻击性"，而是"5宫主火星飞入8宫——你把恋爱里的热烈（5宫）带到亲密共享的暗面（8宫）"。

## 3. 第一层：源宫帽子清单

每个宫是多义词。飞星时所有帽子同时生效。

| 宫 | 帽子1 | 帽子2 | 帽子3 | 帽子4 | 帽子5 | 帽子6 |

| 1 | 自我/人格 | 天赋能力 | 身体健康 | 外貌气质 | 命运轨迹 | 性格底色 |

| 5 | 恋爱/桃花 | 创造力 | 子女 | 投机/博彩 | 娱乐享乐 | 个人魅力 |

### 使用规则

- 飞星时原宫的所有帽子 **同时带入** 目标宫
- 帽子之间不互斥，可同时激活
- 现实中最突出的那顶帽子取决于盘主实际人生经历
- 得吉/受克决定每顶帽子落地时是助力还是阻力

## 4. 第二层：转宫调制

### 4.1 规则

**目标宫是源宫的第几宫，决定了"这段关系是什么性质"。**

以源宫为第1宫，目标宫是它的第N宫 → "源之N"。

### 4.2 转宫底色速查表

| 相对位置 | 正面色调 | 负面色调 | 例子 |
|---------|---------|---------|------|
| 第2宫 | 源宫的钱/资源增值 | 源宫的钱/资源流失 | 4飞5→父亲给恋人花钱 / 父亲好赌 |
| 第3宫 | 源宫的沟通/学习/流动 | 源宫的奔波/口舌 | 4飞6→父亲有技能 / 父亲地位低 |
| 第4宫 | 源宫的家/根基 | 源宫的家庭问题 | 4飞7→伴侣善于经营家庭 / 家庭拖累婚姻 |
| 第5宫 | 源宫的快乐/创造 | 源宫的放纵/沉迷 | 10飞5→事业带来愉悦 / 因纵情毁事业 |
| 第6宫 | 源宫的服务/打磨 | 源宫的劳碌/损耗 | 2飞8→靠技能赚投资财 / 为投资亏钱 |
| 第7宫 | 源宫的合作/伴侣 | 源宫的对抗/敌人 | 4飞10→父亲事业好 / 父母关系不睦 |
| **第8宫** | **源宫的蜕变/杠杆** | **源宫的危机/暗面** | "X之8" = 登神梯 or 心魔关 |
| 第9宫 | 源宫的远见/扩展 | 源宫的理念冲突 | 7飞3→异地良缘 / 三观不合 |
| 第10宫 | 源宫的社会化/上位 | 源宫的社会压力 | 3飞10→口才助事业 / 口舌毁事业 |
| 第11宫 | 源宫的社群化/共享 | 源宫的疏离/群体问题 | 4飞11→家族人脉 / 执念不被理解 |
| 第12宫 | 源宫的灵性/福报 | 源宫的消融/业力 | 4飞3→旅居/漂泊 / 手足争家产 |

### 4.3 特殊：X之8

**任何一个源宫飞入其第8宫，都会呈现强烈的双极性。**
"登神梯"和"心魔关"是一体的两面——不是两个配置，是一个配置的两张脸。

```
4→11: "4之8" → 家庭根基的暗面
  正: 家族人脉铺路，父亲社交圈抬你 → 登神梯
  反: 原生家庭阴影投射到社交，执念不被理解 → 心魔关
```

### 4.4 特殊：同宫反馈

源宫=目标宫 → **自我反馈闭环**。没有外部转宫调制，力量完全内循环。

```
9飞9: 深造→深造 → 知识体系自我强化（正反馈）或偏执（负反馈）
12飞12: 业力→业力 → 深度灵性（正）或沉溺玄学（负）
8飞8: 暗面→暗面 → 极端魅力（正）或极端危险（负）
```

## 5. 第三层：吉凶分化规则

### 5.1 _quality() 判定逻辑

```
hard = 0
对飞星领主的每条 DYNAMIC 相位:
  有接纳 → +0.4（磨合）
  无接纳 + 实星 → +0.8（硬碰）
  无接纳 + 虚点/世代星 → +0.5（外部压力）
尊贵总分 < 0 → +1.0（落陷/失势）

hard ≥ 1.5 → "ke"（受克）
hard < 1.5 → "jin"（得吉）
```

### 5.2 文案生成规则

```
得吉文案 = 同样的材料 + 正面动词（获得、利于、促成、带来帮助）
受克文案 = 同样的材料 + 负面动词（破坏、受损、拖累、带来麻烦）

两个文案是同一个结构的两种结局，不是两套不同的结构。
```

### 5.3 特殊场景处理

**庙旺 + 受克 = "有资质但费力"**
> 例：土星入庙9宫 + 被金星刑未接纳 = 深造天赋9.28 + 考试运一般4.44 → "不是学霸"

**落陷 + 有援军 = "走不通但有替代路线"**
> 例：火星落陷10宫 + 水星接纳 = 事业本身不顺，但水星（2R飞11）带来财务管理路线

**虚点刑克 ≠ 硬碰**
> 北交/南交/莉莉丝的刑冲是"外部压力"（+0.5），不是个人硬碰（+0.8）

## 6. 六亲传导规则

### 6.1 六亲→宫映射

| 人物 | 对应宫位 | 飞星含义 |
|------|---------|---------|
| 自己 | 1宫 | 自身的天赋/精力流入飞入宫 |
| 父亲 | 4宫 | 父亲在飞入宫领域的表现 |
| 母亲 | 10宫 | 母亲在飞入宫领域的表现 |
| 兄弟姐妹 | 3宫 | 手足在飞入宫领域的表现 |
| 子女 | 5宫 | 子女在飞入宫领域的表现 |
| 伴侣 | 7宫 | 伴侣在飞入宫领域的表现 |
| 祖父 | 7宫(4之4) | 转宫：父亲的父亲 |

### 6.2 传导规则

"人物不能搞错"——论的是**谁**在**哪个领域**的表现，对象搞错了后面全错。

## 7. 生成公式（可编程）

```python
def generate_dispositor_text(from_house, to_house, lord, quality):
    """
    from_house: 源宫 (1-12)
    to_house: 目标宫 (1-12)
    lord: 飞星领主
    quality: "jin" | "ke"
    """
    # 1. 取帽子
    hats = HOUSE_HATS[from_house]  # 如4宫 = ["房产","父亲","家族","安全感","祖产","晚年"]
    
    # 2. 取转宫底色
    relative = (to_house - from_house) % 12 + 1  # 目标宫是源宫的第几宫
    tone = RELATIVE_HOUSE_TONES[relative]  # 如第8宫 = "暗面/转化"
    
    # 3. 帽子 × 目标宫领域 × 转宫底色 → 含义线
    meaning_lines = []
    for hat in hats:
        line = f"{hat}在{to_house}宫领域（{HOUSE_ARENA[to_house]}）中{'得吉' if quality=='jin' else '受克'}"
        meaning_lines.append(line)
    
    # 4. 选 jin 或 ke 的动词
    verbs = POSITIVE_VERBS if quality == "jin" else NEGATIVE_VERBS
    
    # 5. 组合输出
    return compose(meaning_lines, tone, verbs)
```
