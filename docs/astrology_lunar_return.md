# 月返（Lunar Return）排盘规范

> 状态：v1 技术规范（2026-08-04）
> 配套实现：`domain/timeline/lunar_return.py` · 复用 `NatalChartCalculator`
> 相关规范：`docs/astrology_timing.md`（推运分层）· `docs/astrology_interpretation.md`

---

## 1. 定义

月返 = 月亮**回到本命月亮黄经**的时刻（每月一次，周期 ~27.3 天）起的盘。
月返盘代表"接下来一个月"的主基调与重心领域。

## 2. 排盘逻辑（定稿）

```
① 本命月亮黄经    取本命盘月亮精确黄经（如夏天：双子1.07° = 61.0677°）

② 求月返时刻      月亮黄经再次等于本命黄经的时刻（正向求根，分钟级）
                  ★ 取"参考时刻之前最近的一次"——这才是正在生效的月返
                  （易错：取成"未来的"下一次，错；月返周期 27.3 天）

③ 排返回盘        以【月返时刻 + 当前所在地经纬度】排盘
                  ★ 当前所在地，不是出生地！宫位随地点变。
                  （易错：用出生地排，错）

④ 判读重点        a. 月返上升（这个月的面具/进入点）
                  b. 月返月亮落宫（这个月的重心领域）——最重要
                  c. 角宫群星（被强化的领域）
                  d. 月返星 vs 本命星相位（触发本命哪个领域）

⑤ 综合            月返 + 法达大限/子限 + 问题征象星/帮手星 + 行运触发窗口
```

## 3. 黄金测试（夏天 · 2026-07 生效 · 当前地杭州富阳）

- 当前生效月返时刻：**2026-07-11 08:25**（Asia/Shanghai）
- 生效区间：2026-07-11 → 下次月返（~08-07）
- 地点：杭州富阳（lat 30.05, lon 119.96）
- 月返上升：狮子 29.8°（末度）
- 月返月亮落 10 宫（双子）→ 事业主战场
- 10 宫群星：月亮 + 火星 + 天王（事业行动/变动）
- 8 宫：土星 + 海王（资源/深度拉扯）

## 4. 判读要点

- **月返月亮落宫 = 这个月的重心**（最重要）：10 宫 = 事业/目标/公众
- **月返上升 = 面具/姿态**：狮子 = 展现/被看见/主导
- **上升末度**：边界月——主题从上一星座转向下一星座（狮子→处女 = 展现→精耕）
- **角宫群星**：如 10 宫月火天王三重激活 = 事业主战场

## 5. 出口（接入星灵 app）

月返计算结果通过 `LunarReturn.to_dict()` 序列化导出（见 `docs/serialization.md`）：
时刻/生效区间/上升/月亮落宫/群星/判读要点，全部 JSON 友好，供 app 消费。

## 6. 诚实边界

- 月返盘是"这个月的主基调"，不是事件预言（前瞻盲测原则）
- 宫位依赖当前地——用户换城市后需重排
- 月返需结合法达大限/子限、问题征象星/帮手星与行运触发窗口综合，不单独下结论
