## 1. 产品概述

**一句话**：一个真正会算占星、会说人话的数字星灵——用真实的星历计算 + 可解释的推理，而不是 LLM 编造。

**产品形态**：对话式 AI 占星伴侣（App/小程序），核心是"问一个关于人生的问题，得到有真实星盘依据的回答"。

**差异化**：
| 同类产品 | 痛点 | Garden-Spirit |
|---------|------|--------------|
| 纯 LLM 占星 bot | 星盘是编的，前后矛盾 | 星盘来自 Swiss Ephemeris 真实计算 |
| 静态占星 App | 只能看报告，不能对话 | 多轮对话，追问可深入 |
| 真人占星师 | 贵、慢、不可复制 | 随时可用，推理过程可审计 |

## 2. 目标用户

- 中文用户，18-35 岁为主
- 对占星、自我探索、人生决策感兴趣
- 典型画像：
  - **职场人**：换工作/升职/创业时机
  - **感情中人**：是否合适/何时结婚/能否复合
  - **自我探索者**：性格解析、情绪周期
  - **习惯型用户**：每日运势、订阅陪伴

## 3. 核心价值主张（三条原则 → 产品承诺）

1. **算得真**——星盘由天文引擎计算，非 LLM 编造
2. **讲得清**——每个结论都有可追溯的证据链（哪个行星/宫位/相位支撑）
3. **陪伴暖**——十大星灵人格，多轮对话有温度

| 黄水晶 Citrine | 阳光鼓励 | 热情、乐观、赋能 |

## 6. 核心用户旅程

```
① 引导 Onboarding
   采集出生数据（时间/地点/时区 + 精度声明）→ 隐私授权
   ↓
② 初识 First Reading
   生成本命盘 → "你是这样的星灵气质"（人格化解读）
   ↓
③ 对话 Dialogue  ← 核心循环
   问问题 → Intent → 领域推理 → Conclusion → 人格化回答
   ↓
④ 人生 K 线 Life Timeline
   可视化未来机会/压力曲线（今日/本月/今年/十年）
   ↓
⑤ 每日陪伴 Daily
   每日运势推送、订阅回访
```

## 7. 关键产品决策（v1，已冻结）

| 决策 | 选择 | 理由 |
|------|------|------|
| 事件问题方法论 | 本命 + 行运时间窗口 | v1 不做卜卦，证据可解释可测试 |
| 合盘范围 | 基础合盘（相位+落宫+互溶） | 支撑感情全部策略，不含 Composite/Davison |
| 星历参数 | 回归黄道 + Placidus（**每用户可切换**） | 与主流占星软件一致；解读标注所用宫位制 |
| 知识库 | YAML 数据驱动 | 占星师可调权重，不改代码 |
| LLM 成本策略 | Domain 先出结论，LLM 仅包装 | 基本解读不耗 token，成本可控 |

## 8. 数据需求与隐私

**必需数据**：出生日期、出生时间（分钟精度）、出生地点 → 经纬度、时区。
**精度降级**：未知出生时间 → 默认正午 + 明确提示"宫位结论精度受限"。

**隐私（红线）**：
- 出生数据属敏感数据，数据库**加密存储**
- 明确隐私授权 + 可随时删除数据
- 不把出生数据用于任何非产品用途

## 9. 安全与合规

- 免责声明：占星不构成医疗/法律/财务建议
- 情绪危机检测：识别自伤/抑郁信号 → 停止占星式回答，给出专业求助引导
- 未成年人保护：涉及感情的深度内容需适龄门槛
- Safety 模块位于 `application/conversation/safety.py`

## 10. 非功能需求

| 维度 | 要求 |
|------|------|
| 准确度 | 星历计算用名人数据黄金测试验证 |
| 可审计 | 每个结论可追溯到规则与证据（权重全部来自 Domain） |
| 成本 | 基本解读可无 LLM 完成；LLM 仅用于意图抽取与转述 |
| 性能 | 单次解读（无 LLM）< 2s；含 LLM < 8s |
| 可扩展 | 新增占星技法 = 加 4 样东西，不改现有代码 |

| 指标 | 目标 | 阶段 |

## 13. 风险

| 风险 | 应对 |
|------|------|
| 占星结论被当作现实决策依据 | 免责声明 + 建议语气措辞 |
| 用户出生时间不准确导致宫位错 | 精度声明 + 生时矫正（v1.5）|
| LLM 越权解释星盘 | 架构防火墙 + 代码评审越界规则 |
| 隐私泄漏 | 加密存储 + 授权 + 可删除 |
