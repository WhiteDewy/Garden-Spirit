# 前端 UI 规范（Frontend UI Conventions）

> 建立日期：2026-08-16 · 背景：注册流程视觉评审中暴露的按钮高度不一、弹层白块、背景断层问题。
> 适用范围：`frontend/` 全部页面（`pages/universe/wheel.vue` 视觉冻结，不适用）。
> 后续所有前端改动必须遵守本规范；新增条目时注明日期与原因。

---

## 1. 按钮规范（全局 · 参考 Apple HIG）

> 流程按钮基线 **80rpx（40pt）/ 圆角 20rpx**；Hero CTA（每屏至多一个）88rpx / 22rpx。宁矮勿高、宁小圆角勿全胶囊，禁止 999rpx。

1. **同高**：同一操作区（如同一步骤的主/次按钮）必须统一 `min-height`，当前基线 **80rpx**。禁止一个按钮靠 padding、另一个靠 min-height 撑高。
2. **居中**：uni-app H5 的 `button` 默认不垂直居中文案，所有按钮必须显式声明：
   ```css
   display: flex; align-items: center; justify-content: center;
   ```
3. **同调性**：同一场景内主/次按钮共享同一套形状语言（圆角 20rpx、字号 25rpx、字重、描边宽度），只允许在填充/颜色上区分层级。
4. **单按钮占满**：操作区用 `grid-template-columns: auto 1fr` 时，若只有一个按钮，必须让它跨满整行（`grid-column: 1 / -1`），不允许缩在 auto 列里。
5. **暗场景按钮**：深色页面中主按钮使用「玻璃金描边」质感（参考 `pages/index/index.vue` 的 `.create-chart-screen .primary-btn`），禁止直接沿用浅色场景的深墨色实心按钮（会和暗背景融为一体）。
6. **表单卡呼吸感**：表单卡片内边距 ≥ 48rpx（上）/36rpx（左右），输入区与操作区间距 ≥ 46rpx，禁止内容贴边或各区块挤在一起。

## 2. 弹层规范

1. **跟随场景明暗**：系统/框架弹层（uni-app picker 的 `.uni-picker-custom` 系）默认是白底，在暗色场景必须用全局（非 scoped）样式覆盖成场景色，禁止出现白色弹块（当前暗色覆盖写在 index.vue 末尾的全局 style 块）。
2. 弹层遮罩不重复加深（框架自带 mask）。

## 3. 场景背景规范

1. **无断层**：每个 stage 的根节点（`.stage-*`）与内容屏（`.create-chart-screen` 等）必须使用同底渐变，不允许 page 级背景在屏幕边缘露出异色断层。
2. 深色 stage（welcome/register/awakening）要隐藏 page 级浅色装饰（`.bg-glow` 等）。

## 4. 星灵森屿视觉基线

- 深空章节（欢迎→注册→绘制星图）统一使用夜空渐变 `#02040d → #04070d`，字体奶白 `#f8f1de`，强调金色 `#f3dfaa`。
- 花园首页保持明亮（晨雾/草木系），两章节之间允许明暗转换，但转换发生在 stage 切换，不允许同屏混用。
- **星点必须有大小层级**（三档尺寸 + 少数亮星），全等尺寸的星点一眼假；参考 index.vue 的 `.sky-star:nth-child()` 分档。

## 5. 全站排版与圆角阶梯（2026-08-16 · 苹果式克制）

> 目标：欢迎页 / 注册页 / 首页（以及后续页面）的文字、按钮、卡片读起来像同一个产品。

**圆角阶梯**：按钮 20rpx｜小卡 28rpx｜中卡 32rpx｜大卡·舞台 40rpx｜chip 全胶囊。禁止同一层级混用多档圆角。

**标题阶梯**（serif：Georgia + Noto Serif SC）：
- H1 问候/大标题 52–56rpx / 字重 800 / 字距 -0.03em
- H2 卡片标题 36–38rpx / 字重 800 / 字距 -0.03em
- H3 小卡标题 28rpx / 字重 750 / 字距 -0.02em

**正文**：25–26rpx，行高 1.8–1.9；次要文字用墨色 60% 透明度；eyebrow 小标签 19–20rpx / 0.16–0.2em 字距 / 800 / 38% 墨色。

**间距节奏**：页面左右边距 36rpx；模块间距 32–40rpx；卡片内边距 大卡 36/32、小卡 24–26。

**按钮基线**：`.primary-btn / .secondary-btn` 基类自带 `min-height 80rpx + flex 居中`（已从局部规则升为基类，任何页面不得另起炉灶）。

## 6. 注册采集字段（2026-08-16 定）

姓名 / 称呼（她/他/先不说，可选）/ 出生日期 / 出生时间（含「不确定」与 1986–91 中国夏令时校正）/ 出生地（国内级联 + 海外输入）/ 现居地（默认同出生地）/ 时区（默认 GMT+8）。
> 注意：现居地与个人时区后端 `Person` 暂无字段，前端已随 `POST /person` 携带并留存 localStorage（`gs_residence` / `gs_timezone`），**后端落库前视为未持久化**。
