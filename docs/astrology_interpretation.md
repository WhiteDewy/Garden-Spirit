# 占星解释引擎规范（HouseSignificationEngine）

> 状态：v1 技术规范（2026-08-04，随开发维护）
> 定位：**横向能力**——对任意盘、任意结构，按"问题域 + 结构质量"产出多维解读。
> 配套实现：`domain/astrology/interpretation/` · `knowledge/house_significations.yaml`
> 测试：`tests/unit/test_house_signification.py`（以真实盘为黄金夹具）
> 相关规范：`docs/astrology_reception.md`（互溶/接纳/末度）

---

## 0. 核心思想：每个宫是"语义场"，不是单义词

一个宫位（如 12宫）含义丰富且随语境漂移：玄学财 / 暗财 / 小人 / 恋爱脑 / 医院 / 潜意识 / 幕后……
真人占星师用**三层过滤器**把控，引擎同样三层：

```
① 语境选择（问题域） → 只激活该域相关含义（防关键词倾倒）
② 结构调制（质量分） → 决定取正面切片还是负面切片
③ 收敛门槛（事件）   → 事件预言需强连接收敛，倾向默认发射
```

---

## 1. 语义场数据（house_significations.yaml）

每个宫位的含义条目：

| 字段 | 说明 |
|------|------|
| `word` | 精确描述 |
| `domains` | 激活的问题域（career/relationship/wealth/health/emotion/family/learning/self） |
| `polarity` | positive / negative / neutral（本身极性，结构调制后倾斜） |
| `intensity` | 语义场基础强度 1-5 |
| `resonance` | 通俗共鸣词（LLM 转述锚点，**确定性数据，不发明**） |
| `gated` | tendency（倾向，默认）/ event（事件预言，高门槛） |
| `requires_corroboration` + `corroborate_houses` | event 条目的强连接收敛要求 |

**解读优先级**：P1 倾向切片默认；P2 事件切片需收敛数达标 + 域激活 + 非预言护栏。

## 2. 三层过滤器

### 2.1 语境选择（域过滤）

```
对每个宫：eligible = 语义场中 domains 含"问题域"的条目
问财 → 只激活 money 域含义；问情 → 只激活 relationship 域含义。
```

防"关键词倾倒"：同一个 12宫，问财绝不甩"小人"，问情绝不甩"玄学财"。

### 2.2 结构调制（吉凶两论，不抵消）

**吉凶分开累积、各自出解读、各自带证据，永不净合。**

`_house_quality_dual(chart, house) -> (吉分量, 凶分量, 吉证据, 凶证据)`：

| 分量 | 来源 | 驱动 |
|------|------|------|
| **吉** | 庙旺尊贵、吉星、和谐相、宫内吉星 | 正向解读（positive 条目） |
| **凶** | 凶星、刑冲（未接纳重罚/有接纳轻罚）、宫内凶星 | 负向解读（negative 条目） |

强度：positive 条目吃吉分量 `base×(1+吉×0.4)`；negative 条目吃凶分量 `base×(1+凶×0.4)`；
中性条目取较大者。证据按极性轨道分派（吉轨证据 / 凶轨证据），各论各的。

**刑克接纳调制**：刑冲有接纳 = 磨合（凶分量 +0.4），无接纳 = 硬碰（凶分量 +0.8）。
**庙旺 ≠ 强项**：庙+受克 = "有资质但费力"。

**实例（夏天盘 9宫）**：土星庙（吉）+ 金星刑未接纳/木星冲磨合（凶）→
吉轨"深造/专业体系 9.28"与凶轨"考试运一般/深造费力 4.44"**同时浮出**，各带证据。
综合"不是学霸"由吉凶两论自然涌现，而非单标量抵消。

### 2.3 收敛门槛（事件预言）

`gated: event` 的条目（如三方关系）需与 `corroborate_houses` 的强连接数
（≥ `requires_corroboration`）达标才发射；否则不产出。强连接 = 互溶/激活接纳/主相位（≥2.5）。

**实例**：12宫"三方关系"需 2 强连接收敛；夏天盘 12↔7/8 仅"潜在"弱连接 → 正确不发射。

## 3. 宫位交感（一星多宫主）

一个行星管多个宫位 → 这些领域互相传导、共享该星特质。
`detect_synapsis(chart, kb)` 自动检测 ≥2 宫的枢纽星。

**实例**（夏天盘，自动发现）：
- 水星 = 1/2/5 宫主，落11宫 —— 自我×财帛×恋爱 经沟通/技术交感
- 木星 = 7/8/11 宫主，落3宫 —— 伴侣×亲密共享×社群 经表达/教学显化
- 土星 = 9/10 宫主，落9宫 —— 事业×高等学问 经土星交感

---

## 4. 连接分级

两宫主之间的连接类型与强度（`ConnectionClassifier`）：

| 类型 | 强度 | 条件 |
|------|------|------|
| reception_mutual | 4.0 | 双向尊严（庙旺互溶） |
| reception_active | 3.0 | 单向接纳 + 相位激活 |
| aspect | 2.5 | 主相位 |
| flight | 2.0 | 宫主飞宫（含末度） |
| cohabit | 1.0 | 同宫/同座/同主 |
| reception_latent | 0.5 | 单向尊严无相位（未激活） |

- 事件收敛：强连接 ≥ 2.5 计入。
- 与 `docs/astrology_reception.md` 的互溶/接纳规则一致（含三分主 all/sect、三王星虚点排除）。

---

## 5. 末度入宫（effective_house）

行星距下一宫头 ≤ 5° → 主影响下一宫（双宫都算，近的为主）。

**实例**：火星双子 23.3°，2宫头双子 23.5°，距 0.2° → effective_house = 2。
12R火星"飞2宫" → 12宫的钱财类含义（玄学财/暗财）飞行增强。

---

## 6. 共振词（resonance）

每条解读携带通俗共鸣词（如 恋爱脑/地下恋/暗财），挂 Domain 数据上，
LLM 转述时只做锚点，**不发明**（原则三）。配合"专业→共鸣→落地"三层转述。

---

## 7. 本命解读（natal_reading）

`interpretation/natal.py` 跨 8 域组合各宫语义场，产出结构化本命解读
（对应 PRD"初识 First Reading"场景）。直接可调用、可测试。
