# 10 星灵 AI 生成 Prompt 清单（治愈插画风）

> 用途：为首页「星灵接引」批量生成 10 张治愈风星灵立绘（透明 PNG），替换/升级现有行星图标。
> 平台：即梦 / 豆包 / Midjourney 通用。生成后需**抠图**（AI 出不了真透明底）。
> 落位：`frontend/src/static/imgs/spirits/`，命名 `spirit_<planet>.png`（如 spirit_moon.png），走现有 `@error` 兜底链。

---

## 0. 通用风格基座（每条 prompt 都拼上这段）

```
治愈系插画，温柔治愈的风格，柔和磨砂水彩质感，圆润可爱的轮廓，
暖色调氛围光，细腻光影，留白干净，半身特写，
一位治愈星灵拟人形象，无文字，无水印，无边框，纯色浅色背景
```

> 平台差异：
> - **即梦 / 豆包**：直接把「角色句 + 风格基座 + 输出要求」整段粘贴。
> - **Midjourney**：角色句用英文，末尾追加 `--no text, watermark --ar 1:1 --style raw`；背景指定纯色（如 `plain soft beige background`）方便抠图。
> - 抠图：`remove.bg`（网页）或 PS「选择主体」，导出透明 PNG。

## 输出要求（每条 prompt 末尾追加）

```
全身/半身立绘，居中，画幅 1:1，背景为纯净浅色（米白/浅绿）便于抠图，
人物占画面 70% 以上，无任何文字、无边框、无装饰字符、无水印
```

## 使用流程

1. 用上表 10 条 prompt 批量生成（即梦/豆包可一次跑一套，出图后挑每颗星最满意的 1-2 张）。
2. 抠图 → 透明 PNG → 压到 512px（沿用 sharp 流程，参考 `_raw_imgs/` 处理经验）。
3. 放 `frontend/src/static/imgs/spirits/spirit_<planet>.png`。
4. 前端：首页星灵位优先加载立绘，无图时回落现有行星 PNG / CSS 光球（兜底链不炸）。
5. 10 颗星尽量一次性定稿统一风格——风格不一致会破坏"同一座花园"的观感。

## 备选：不抠图的做法

如果嫌抠图麻烦，可以让背景直接出「花园同款浅绿草地」，立绘底部融入草地（像站在草地上的角色）——但这样场景背景固定，昼夜切换时角色会"悬空"，所以**推荐抠透明底**。
