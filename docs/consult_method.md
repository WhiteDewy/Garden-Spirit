# 一对一咨询方法论（Consult Method）

> 来源：Garden-Spirit 项目查缺补漏咨询（2026-08-05，占星师夏天逐条验证）
> 用途：指导系统的**咨询节奏**（何时讲本命/何时看推运/如何对话验证）+ 事业领域解盘专章
> 与 `meng_method.md` 的关系：meng_method 是"解盘技法"（怎么读一张盘）；本文是"咨询流程"（怎么把盘讲给用户、怎么和用户一起验证）。二者互补。
> 铁律：本方法论只决定"算哪些结构、讲哪些结论"，**极性/吉凶/权重永远来自 Domain 确定性计算，LLM 只转述不推理**（原则三）。

---

## 一、总纲：本命为基调，推运为补充

### 1.1 本命盘是长期基调，永远不变

**任何推运盘、行运、法达，都是基于本命盘去判断的。** 本命盘给出的是一个人一生的结构基调：

- 哪颗星是某领域的宫主星（掌宫）
- 这颗星自己是强是弱（尊贵/失时/受克）
- 谁在帮它（接纳/互溶）、谁在压它（刑冲）

这一层**不变**。先讲清楚它，用户才能理解"我为什么会是这样的人"。

### 1.2 推运/行运/法达只回答"当前在讲哪一章"

本命盘定"你有什么"，时间技术定"现在走到哪一步"：

| 时间技术 | 回答的问题 |
|---------|-----------|
| 法达（Firdaria） | 现在哪颗星在"管事"？这一章（约10年）/子段（约1年）的主题是什么 |
| 问题征象星/宫主星 | 本轮问题真正由哪些本命承载者负责（如婚姻=7R+金星+5R，事业=10R+6R） |
| 接纳/互溶帮手星 | 宫主星弱或受克时，谁在帮它显化、绕路或解围 |
| 行运 | 具体某月某日，哪颗行运星激活了本命哪个结构 |

**关键**：时间技术**不能脱离本命结构单独存在**。说"今年走日运"没有意义，必须说"日运激活了你本命11宫的太阳"才完整。

### 1.3 咨询顺序：本命基调 → 当前章节 → 对话验证 → 补推运

```
① 先讲本命结构基调
   这颗星管什么、自己强不强、谁在帮/谁在压
   ↓
② 再讲当前走到哪一章
   法达大限/子限 → 现在这颗时间领主激活了哪个本命结构；本轮问题征象星/帮手星是行运要观察的对象
   ↓
③ 和用户对话验证
   把结构讲给用户，请 TA 说说现状，用现状核对结构
   （例："你10宫主土星落9宫，你是不是在深耕一门学问？"）
   ↓
④ 验证通过后，才补充行运时机
   具体哪个月有利/要留意
```

**绝对不要**：跳过①②，直接从③或④开始——那是拿一张推运盘空谈，用户听不懂，也验证不了。

## 二、总纲：掌宫优于落宫，链式追踪

（此节是 meng_method §1 的系统化，咨询时作为判断主线）

### 2.1 从问题出发，锁定宫主星

| 问什么 | 直奔哪个宫主星 |
|--------|--------------|
| 事业/职业/技能 | 10宫主（事业）+ 6宫主（日常技能）|
| 感情 | 金星/火星/月亮 + 5宫主（心动）+ 7宫主（婚姻对象）|
| 财运 | 2宫主（正财）+ 8宫主（偏财/他人资源）+ 11宫主（进账）|
| 健康 | 6宫主 + 1宫主 |
| 学习 | 3宫主 + 9宫主 |

### 2.2 劫夺必须处理

一个宫可能有**两个宫主**（宫头星座守护 + 被劫夺星座守护）。判"谁管这个宫"时两个都要算。

```
例（夏天盘）：6宫头天秤（金星）+ 劫夺天蝎（火星）→ 6宫主 = 金星、火星双主
```

漏掉劫夺 = 漏掉半个宫主，结论必然偏。

### 2.3 宫主星状态 = 能不能扛

锁定宫主星后，第一步判它自己行不行：
- 尊贵（入庙/入旺 = 能扛；落陷/失势 = 弱）
- 失时（日生盘的火星落阴性星座）
- 受克多少

**入庙能扛**：即使被凶相位刑冲，入庙/入旺的宫主星也"扛得住"——凶相位是压力，不是垮台。

### 2.4 链式追踪：谁在帮它，谁才是实际显化的

宫主星弱的时候，**帮它的星（接纳/互溶/吉相）才是实际显化的领域**。

```
10宫主火星(落陷,弱) ← 水星接纳(援军)
                          ↓
                    水星 = 2宫主飞11宫
                          ↓
                    实际职业 = 财务高管（不是火星的事业，是水星的事业）
```

**宫主星是剧本，帮它的星是主演。**

### 2.5 互溶/接纳 = 不止一份工作/技能

**被木星互溶/接纳**尤其重要——木星是扩张星，被它互溶的星代表的领域会"多线程、多份、跨界"。

```
例（夏天盘）：太阳 ↔ 木星互溶（domicile 级）
→ 太阳的事业能量被木星扩张 → 不止一份工作/技能
  程序员 + 学AI + 学玄学 = 多线程发展
```

看到互溶/接纳，系统**必须**提示"这可能是多线发展，要和用户确认实际在做几件事"。

## 三、总纲：对话验证，不讲独白

### 3.1 结构是假设，现状是证据

本命结构是一套**假设**。用户的现状（做什么工作、学的什么、正在经历什么）是**验证**。二者对上，结论才成立。

### 3.2 验证话术模板

```
"我看了你的盘，10宫主土星落在9宫（深耕学问的位置）。
 你现在是不是在做一门需要长期钻研的事情？——   ← 讲结构，请用户对现状
 如果是，那这条线就通了，我接着说："
```

- 用户说"对" → 结构验证通过，可以深入 + 补推运时机
- 用户说"不对" → 结构没对上，换链/换宫，不要硬讲

### 3.3 每轮咨询只验证一条主线

不要一次抛五条结论让用户接。**一轮讲一条主线，验证过了再讲下一条。**

## 四、总纲：给出路，不给绝路（咨询伦理）

（与 meng_method §5 一致，此处强调咨询场景）

- 凶相位给压力，但**入庙能扛**——这是出路
- "飞星只代表过程，不代表最终结果"——过程差 ≠ 结局差
- 抽象的凶 → 具体可操作的注意点（"火星大运注意炎症/磕碰"而非"你必有灾"）
- 全盘很苦的人 → 挑出盘里好的星 + 对应法达的年份，给人期待

## 五、事业专章（职业 / 工作 / 技能）

### 5.1 事业核心结构（优先级从高到低）

判断事业的长期基调，依次看：

1. **10宫主**（事业名望）——包括劫夺双主
2. **6宫主**（日常技能/工作内容）——包括劫夺双主
3. **10/6宫内的星**（落在事业宫/工作宫的星）
4. **与以上结构的关联**（相位/互溶/接纳）——尤其是被木星互溶接纳

**不要**只看某颗行星的孤立相位（如"火星刑太阳"）。事业主线是**宫主星**，不是随机相位。

### 5.2 10宫主状态 → 事业长期基调

| 10宫主状态 | 事业基调 |
|-----------|---------|
| 入庙/入旺 | 事业根基强，能扛压力——即使刑冲，是压力不是垮台 |
| 落陷/失势 | 事业根基弱，需要援军（谁接纳/互溶它）才是实际显化 |
| 落9宫 | 蓄力期——在深造/学问/跨领域积累，还没到事业顶点 |
| 落10宫 | 发力期——直接显化在事业地位 |

**例（夏天盘）**：10宫头宝瓶 → 10宫主土星 → 土星本命落9宫、宝瓶座入庙。
> "事业根基强（土星入庙能扛），但土星落在9宫——现在在蓄力（深耕学问），还没进10宫发力。"

### 5.3 6宫 vs 10宫：当前在哪段发力

- **6宫发力**：现在靠日常工作/技能立足（程序员、某个具体工种）
- **10宫发力**：已经站上事业地位（管理、名望、行业地位）

系统要能说出"你现在是 6 宫在发力（靠技能吃饭），10 宫还在蓄力"——这是用户最关心的"我现在到底处在哪个阶段"。

### 5.4 法达 × 本命：当前这一章在讲什么

```
法达大限/子限激活某颗星
   ↓
这颗星本命管哪个宫（掌宫）+ 落在哪个宫
   ↓
= 这一章（约10年）在讲那个领域的事
```

**例（夏天盘）**：
```
月亮大限（2022-03~2031-03，月落1宫，情绪/自我/新起点）
   ↓ 子限
2027-05 起太阳子限 → 激活太阳 → 太阳本命在11宫（新技术/社群/理想）
   ↓
这一章在讲"把自己的新技能（AI/玄学）带入 11 宫的社群/理想领域"
```

### 5.5 行运激活宫主星 → 时机

时间领主（法达子限）激活的星，看它**六合/合相到谁**：

- 激活的星 = 本命宫主星（如太阳落11宫）→ 那一宫的能量被点燃
- 激活的星**六合/三合到10宫主** → 事业能量被激活，但看10宫主落在哪宫决定是"蓄力"还是"发力"

**例（夏天盘）**：
```
太阳子限（日运）--六合--> 土星（10宫主，落9宫）
   ↓
日运激活了10宫主 → 但土星在9宫（不在10宫）→ "蓄力"
   → 讲给用户：明年学的东西开始显形、为进10宫铺路，
      不是直接到事业顶点
```

### 5.6 事业结论模板

```
事业核心：10宫主=土星（宝瓶），本命落9宫、入庙。
状态：事业根基强（入庙能扛），当前蓄力（落9宫深耕），未到10宫发力。
互溶：太阳↔木星互溶 → 多线发展（不止一份工作/技能）。
当前章节：月亮大限→太阳子限（2027-05起），日运激活11宫太阳 → 新技能带进社群/理想领域。
时机：日运六合10宫主土星 → 2027年为进10宫铺路（蓄力），具体时机看行运对土星/太阳的引动。
```

## 七、编译进 LLM prompt 的核心框架（转述层）

以下内容编译进 `response.py` 的 system prompt，约束 LLM **转述的语气与节奏**（不改变任何结论/极性）：

```
## 咨询节奏（consult_method 编译）
1. 本命基调优先：先讲盘主这个领域的长期结构（哪颗星管它、强不强、谁帮谁压），
   再讲当前走到哪一章（法达大限/子限），并说明本轮问题要观察哪些征象星/帮手星。
2. 用结构引出对话：讲完一条主线后，请盘主说说现状来核对，
   而不是一次性抛五条结论。验证过了再深入。
3. 给出路：凶相位是压力，入庙能扛。过程差不等于结局差。
   把抽象的凶变成具体可操作的注意点。
4. 蓄力/发力要讲清楚：宫主星落9宫/12宫等是蓄力期，落10宫/1宫是发力期。
   用户最关心"我现在在哪段"。
```
