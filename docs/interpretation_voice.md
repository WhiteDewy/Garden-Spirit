# 解读语气规范（Interpretation Voice Standard）

> 本规范约束**所有**占星解读的内容写作——包括 `knowledge/rules/*.yaml` 的模板内容，
> 以及 LLM Response 层的提示词。目标是让每一条解读都**有刺、可识别、真实**。
>
> 版本：v1 · 2026-08-03

## 0. 共鸣的两层边界（最重要的前提）

| 层 | 是什么 | 谁负责 | 约束 |
|----|--------|--------|------|
| **内容共鸣** | "这就是我，说得真准"——那份**刺** | **Domain**（模板作者） | 刺必须在 Domain 模板里写好 |
| **语言共鸣** | "说到了我心坎里"——**语气** | LLM（Response 层） | LLM 只换语气，不换内容 |

**铁律**：
- LLM 只能让真话说得动人，不能让空话变动人。
- 禁止让 LLM 为"共鸣"编造占星洞见（违反原则三）。
- 不是每张盘都有戏。平静的配置要说平静，**宁可真实平淡，不可编造戏剧**。

## 1. 五条说话标准

### ① 命名伤口，不说教
**禁止**：`需要注意太阳与土星的平衡`（抽象、教育腔）
**应该**：`你会把伴侣的务实读成"我做得还不够好"`（命名具体的心理反应）

### ② 点出行为模式（具体动词）
**禁止**：`关系里可能存在付出不平衡`
**应该**：`你不自觉地过度付出、拼命证明自己，用"做得好"去换被认可的资格`

### ③ 指出投射（你在对方身上看到的，其实是你自己的功课）
**禁止**：`对方可能比较严肃`
**应该**：`你会在某个时刻发现，你一直在和一个"你以为在给你打分的人"较劲，而对方可能根本没在打分`

### ④ 用相位状态给时态
- **入相** = 正在演化的功课 → 用现在时、进行感（`这是当下正在做功的一条`）
- **出相** = 正在淡去的旧事 → 用过去时（`情绪上的小摩擦正在退场`）
- 入相/出相对比本身可作解读点（`一个退场、一个上场`）

### ⑤ 给功课，不给正确废话
**禁止**：`学会在两者之间找到平衡`（正确但无用）
**应该**：`真正的功课不是平衡，是停止用付出去买被爱的资格`（一个动词，不是一个形容词）

## 2. 内容模板的结构要求

每条解读模板产出 `core_insight`（一句带刺的核心），并携带：

```yaml
rule_id: planet_pair:mars_moon:dynamic   # 可审计
core_insight: "欲望与情感拉扯——你会热烈地要，却在真的深入时本能退缩"
supporting: ["火星落5宫(恋爱舞台)", "月亮落8宫(亲密领域)", "火月四分"]
polarity / weight / confidence            # Domain 判定
```

## 3. 人格是语气的放大器，不是内容的稀释器

同一个刺，十种说法：

| 人格 | 同一条刺的说法 |
|------|--------------|
| 锆石·理性 | "你一直在和一个你以为在给你打分的人较劲——这值得你停下来看看。" |
| 黄水晶·阳光 | "嘿，你其实早就够好了，是你自己一直在加考。" |
| 粉晶·疗愈 | "你总是先证明自己才敢被爱……抱抱那个一直很努力的小孩。" |

**约束**：人格可以换语气/节奏/隐喻，**不能**削弱或篡改核心判断（极性/权重/结论不变）。

## 4. 模板写作自查清单

- [ ] 有具体动词，不是抽象形容词？
- [ ] 命名了心理反应或伤口？
- [ ] 指出了投射或行为模式？
- [ ] 用了入相/出相给出时态？
- [ ] 功课是一个可执行的动词？
- [ ] 没有正确废话（"注意平衡"类）？
- [ ] 没有编造盘里没有的戏剧？
