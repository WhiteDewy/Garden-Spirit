# 六层 Agent 差距施工清单（Gap Checklist）

> 状态：**待施工**（2026-08-10 落档）
> 数据来源：全量代码核实 + `docs/frontend_backlog.md`（2026-08-10 双 agent 盘点）+ `docs/self_map_design.md`（§11 待定）+ PRD §12 待开始
> 用途：后续会话按图施工的「每层还剩什么」清单。口径：**后端能返回 ≠ 前端已渲染；骨架做完 ≠ 每层成熟**。

## 总览：六层骨架全部落地，成熟度差距

| 层 | 骨架 | 成熟度 | 主要缺口 |
|----|------|--------|----------|
| L1 理解 | ✅ | 90% | YAML 词典补全、年度/月度框架、related_person 多轮断链 |
| L2 推理 | ✅ | 95% | 占星深化（合盘/技法/生时矫正） |
| L3 叙事 | ✅ | 90% | **前端接线**（富字段/人格切换/模式选择） |
| L4 记忆 | ✅ | 90% | 日记/时间线页面、星灵选择机制 |
| L5 学习 | ✅ | 75% | **前端录入入口缺失**，真实闭环只在测试跑 |
| L6 行动 | ✅ | 80% | 偏好/退订 UI、待验证提醒推送、成长报告/活态层 |

**核心认知**：六层后端全在，但用户摸得到的只有一部分。优先级最高的是「前端接线」与「用户侧闭环断裂」，不是占星深化。

## 建议施工顺序

**第一批（1-2 天，做完像完整产品）**
1. 聊天富字段展示（L3，纯前端零后端）
2. 人生事件录入前端（L5，激活信任校准闭环）
3. 偏好设置页 + 退订（L6，解「推送只进不出」）
4. DELETE 数据入口（横切，合规）

**第二批（核心产品亮点）**
5. 星灵选择机制（L4，行运推荐 + 自选）
6. related_person 多轮修通（L1，`_restore_related_person` 落库实现）
7. 待验证提醒推送（L6）

**第三批（成长循环收口）**
8. 成长报告（L6）→ 组合模式（L2 之上）→ 格子反转/行运微亮（L6）
