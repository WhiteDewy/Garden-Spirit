# 星灵花园 · 前端视觉重构方向（竞品调研版）

> 状态：**旧方案废弃，方向重定稿**（2026-08-14）  
> 结论：放弃「窗边暮色 · 一盏灯」方向，改为 **「星灵森屿 · 会长大的内在伙伴宇宙」**。  
> 范围：除 `frontend/src/pages/universe/wheel.vue`（自我星盘轮）外，首页、聊天、信箱、我的宇宙枢纽、主题观星台等页面整体重构。
> 参考对象：Tolan、林间聊愈室、万象有灵，以及 Co-Star / The Pattern / Headspace Ebb / Wysa 等 AI 陪伴、疗愈、占星、自我探索产品。

---

## 0. 为什么推翻上一版

上一版「暮色房间 + 一盏灯」有疗愈感，但它的问题很明确：

- 太静、太像独立艺术页，不像一个能长期使用的陪伴 App。
- 太抽象，缺少 Tolan / 林间聊愈室那种一眼可记住的「伙伴角色」。
- 太暗，容易把产品带向小众冥想、信纸、诗性独白，而不是年轻用户愿意每天打开的世界。
- 和项目已有的「10 星灵 / 自我星盘轮 / 记忆点亮 / 成长复利」不够贴合。

新的方向必须先回答一个问题：**用户为什么第二天还想回来？**

答案不应该是“看卡片 / 看报告”，而是：

> **我想回去看看我的星灵、我的小宇宙今天长成什么样了。**

## 1. 竞品关键观察

### 1.1 Tolan：出圈点不是聊天，是「有身体的伙伴 + 会生长的小世界」

Tolan 的核心不是把 AI 聊天包装得更漂亮，而是把 AI 变成一个非人类、可爱、有表达力、不会假装真人的 embodied companion。

值得吸收：

- **角色优先**：用户先记住那个外星伙伴，再进入对话。
- **非人类形态**：避免真人/恋爱/治疗师拟态，降低不适感和依赖风险。
- **小星球/小世界**：关系不是用分数表达，而是用世界变化表达。
- **温暖但不幼稚**：曲线、有机、柔软、轻 3D / 手作感。
- **成长慢慢发生**：世界随关系变深而生长，不是即时打卡奖励。

对 Garden-Spirit 的启发：

> 我们的 10 星灵不能只是列表 / 图标 / 人格配置，它们应该是住在用户内在宇宙里的 10 个伙伴。

### 1.2 林间聊愈室：出圈点是「可爱动物 + 情绪旅程 + 记忆星系」

林间聊愈室强调暖心 AI 小动物、情绪陪伴、成长计划、记忆星系与长期陪伴。

值得吸收：

- **疗愈入口非常低门槛**：不是“咨询”，而是“找小动物说说”。
- **可爱但有陪伴深度**：画风亲近，功能承载情绪梳理、成长计划、早晚音频等。
- **记忆可视化**：用户喜欢“它记得我”，而不是每次重新介绍自己。
- **旅程感**：用户评价里提到“人生还在进行”的感觉，这比普通聊天记录更强。
- **轻游戏化**：服装、鲜花、成长、疗愈时长等可以增加回访动力，但不能压过疗愈本身。

对 Garden-Spirit 的启发：

> 点亮碎片、来信、被照见、行动 +20 都不该只是文字提示，而应该让用户的「内在森屿」发生可见变化。

### 1.3 万象有灵：方向接近，但偏概念重、系统重

万象有灵以阴阳五行和十神人格为核心，每天唤醒不同的“你”，强调多虚拟人格、成长轨迹、情绪能量图鉴和精神宇宙。

值得吸收：

- **多人格结构**：把内在拆成多个长期并存、动态变化的角色。
- **每日唤醒**：每天不是打开同一个页面，而是今天某个内在面向醒来。
- **成长解锁**：不同角色有独立成长进度。
- **精神宇宙**：用户不是在用工具，而是在经营一个象征性的内在世界。

需要避开的点：

- 概念密度太高会变玄、变重。
- 如果全是系统名词，用户会觉得在读设定，不是在被陪伴。

对 Garden-Spirit 的启发：

> 我们可以保留“十个内在面向”的结构，但视觉和交互要比万象更轻、更温柔、更容易进入。

### 1.4 AI 疗愈 / 心理陪伴类：不能装成治疗，应该做「自我反思伙伴」

Headspace Ebb、Wysa、KRIYA 等方向说明：AI 疗愈产品真正可信的部分，不是“像治疗师”，而是安全、透明、支持自我反思。

值得吸收：

- **定位要克制**：生活化陪伴 / 自我整理 / 情绪反思，不做医疗治疗承诺。
- **反思而非评判**：用户需要被帮助理解自己，不是被仪表盘打分。
- **透明与安全**：解释为什么这样回应、何时需要真人支持。
- **少 KPI 化**：目标、提醒、连续打卡容易制造压力；成长更适合用温柔的变化表达。

对 Garden-Spirit 的启发：

> 我们要做“星盘语言里的自我反思”，不是 AI 心理治疗，也不是算命断语。

### 1.5 占星类：现代占星 App 赢在「人格洞察 + 编辑感」，不赢在玄学装饰

Co-Star / The Pattern 的共性：

- 用强文本、人格洞察、关系洞察建立信任。
- 少用复杂神秘装饰，多用现代排版和强烈品牌感。
- 占星术语不应该压到用户前面，用户要先感到“这句话像我”。

对 Garden-Spirit 的启发：

> 占星应该成为内在世界的底层逻辑和证据链，而不是表层到处铺星座符号。

## 2. 新方向一句话

# 星灵森屿 · 会长大的内在伙伴宇宙

用户不是进入一个“占星工具”，也不是进入一个“心理咨询室”。

用户进入的是一个柔软、明亮、带一点奇幻的内在小宇宙：

- 10 个星灵住在里面。
- 每天有一个星灵醒来陪用户说话。
- 用户说过的话，会变成星星、花、树洞、回声、路径。
- 星盘不是冷冰冰的报告，而是这座宇宙的地形、天气和生长规律。
- 成长不是分数，而是这个世界慢慢变得更丰富。

## 3. 品牌气质

关键词：

- **柔软**：低压力、低攻击性、低控制感。
- **有灵**：万物轻轻回应用户，不是死界面。
- **伙伴感**：星灵是同伴，不是老师、神明、医生、恋人。
- **自我探索**：每个功能都指向“更理解自己一点”。
- **轻奇幻**：像森林、星屿、小宇宙、精灵手账，但不要玄学神坛感。
- **明亮疗愈**：不再全屏深暗，主色更偏晨雾、草木、奶油、星光。

一句产品气质：

> **像走进一座住着星灵的小森林，它知道你的星盘，也记得你说过的话。**

## 4. 视觉系统

### 4.1 主视觉基调

废弃：

- 深绿玻璃卡片。
- 暮色房间 / 一盏灯。
- 大面积深紫星空。
- 玄学水晶球 / 霓虹星盘 / 赛博占星。
- 纯文字报告型 App。

采用：

- **明亮柔和的森屿世界**：晨雾、浅草、奶油白、星尘金、淡蓝紫。
- **轻 3D / 软插画 / 泥塑感角色**：圆润、不复杂、不拟真人。
- **可生长的场景**：星灵岛、树洞、花、星尘、云、路径、记忆星座。
- **现代干净 UI**：页面不要儿童游戏化；信息层级仍然要克制、好读。

### 4.3 角色语言

10 星灵不走真人、不走宝石、不走宠物复制，而走：

> **星球小生灵 / 森林星灵 / 软质非人伙伴**

规则：

- 每个星灵有稳定轮廓：太阳圆、月亮软、火星尖一点、土星厚重、水星轻快。
- 每个星灵有一个小动作：太阳伸展、月亮靠近、水星转圈、土星坐稳。
- 每个星灵可以有住所/小地形：太阳坡、月亮池、水星风铃、土星石阶。
- 星灵形象不要太幼儿，也不要像二次元恋爱角色。
- 重点是“可信的陪伴物”，不是“卖萌宠物”。

### 4.4 UI 形状

- 大面积背景：柔和渐变 + 插画场景。
- 功能入口：像场景里的地点，而不是卡片。
- 内容承载：半透明奶白浮层 / 软纸片 / 星尘便签。
- 按钮：圆润胶囊，但不强游戏化。
- 图标：线性 + 手绘感混合，少 emoji。

## 5. 页面方向

### 5.1 首页：星灵森屿 / 今日醒来的星灵

首页不再是“回家房间”，而是：

```text
顶部：今天醒来的是谁？ + 一句今日星语
中部：当前星灵站在小森屿 / 小星球上
周围：今日来信、继续昨天、记忆星尘、待验证小光点
底部：聊聊 / 信箱 / 宇宙 / 主题观星台
```

核心视觉：

- 一个会呼吸的小星灵。
- 一块小岛 / 小森林 / 星尘地形。
- 点亮过的碎片变成小花、星点、树叶、路径。
- 未读来信是漂来的信封 / 树洞回声。
- 待验证判断是望远镜旁边的小闪光，不是红色警报。

首页文案：

- “今天醒来的是月亮。”
- “它好像想陪你，把心里那团雾慢慢说清。”
- “昨天那句话，还在树洞里等你。”

### 5.2 聊天页：和一个星灵散步式聊天

聊天不是严肃咨询，也不是 IM 工具。

视觉：

- 顶部是星灵头像/半身 + 当前状态。
- 聊天气泡可以保留，但背景要像一条森林小径 / 云雾空间。
- AI 回复旁边出现星灵表情和小动作。
- 点亮/被照见/行动反馈变成“星尘落下 / 小芽长出”。

交互：

- 用户不想说时，给 2-3 个轻问题，而不是空输入框压力。
- 支持“只想被听 / 想要建议 / 想看星盘怎么说”三种轻切换。
- `keepsake_created` 显示为“这句话被放进了树洞”。

### 5.3 信箱：树洞回声 / 星灵留下的小纸条

信箱不再走老派信纸，而是“树洞里收集的回声”。

视觉：

- 今日来信像从树洞里飘出的纸条。
- 过往来信像收进一本柔软手账。
- keepsake 是被星灵珍藏的一片叶子 / 一张小纸。
- 灵魂碎片脚注是星尘标签。

### 5.4 我的宇宙枢纽：星灵森屿地图

枢纽页是“地图”，不是两个卡片。

结构：

- 中央：用户的内在森屿地图。
- 左侧入口：自我星盘轮（保持现有页面，不改内部）。
- 右侧入口：主题观星台。
- 下方：记忆星座 / 成长路径 / 星灵图鉴。

注意：

- `wheel.vue` 继续不改。
- 入口要能自然过渡到旧 wheel 风格，可以用“进入旧星图仪”的说法弱化风格差异。

### 5.5 主题观星台：星图手账

主题观星台不能太可爱，否则专业感下降；也不能太报告化。

视觉：

- 像森屿里的观星台。
- 结论是手账段落。
- 证据链是小星图旁注。
- 待验证判断是“这颗星的光，你觉得像不像你？”

文案：

- “我先把盘里的线索摆在这里，你来告诉我哪一句像你。”
- “这不是判决，只是一种倾向，我们一起校准。”

## 6. 差异化定位

竞品已经有：

- Tolan：外星 AI 伙伴 + 小星球。
- 林间聊愈室：AI 小动物 + 疗愈工具 + 记忆星系。
- 万象有灵：十神人格 + 五行情绪宇宙。
- Co-Star / The Pattern：现代占星人格洞察。

Garden-Spirit 应该占的位置：

> **占星驱动的内在伙伴宇宙。**

不是纯 AI 陪伴，不是纯心理疗愈，不是纯占星报告。

护城河：

- 10 星灵 = 内在十种声音。
- 出生盘 = 世界地形和解释底座。
- 点亮账本 = 用户自我理解的生长轨迹。
- 来信/树洞 = 对话变成可回看的情绪证据。
- 验证机制 = 不强行定义用户，而是和用户一起校准。

## 7. 推荐落地顺序

### P0：先做一个新 demo，不动业务页

只重做 `frontend/prototype_home.html`，目标是验证方向：

1. 首页：星灵森屿 + 今日醒来的星灵。
2. 聊天：星灵陪你散步式对话。
3. 信箱：树洞回声。
4. 我的宇宙：森屿地图 + 两个入口。
5. 咨询：观星台手账。

验收：用户一眼能感觉到「Tolan 的伙伴感 + 林间的疗愈感 + 万象的内在人格宇宙」，但又明显是 Garden-Spirit。

### P1：demo 认可后再进 Vue

1. `uni.scss` 加新 tokens。
2. 首页先改，建立世界观。
3. 聊天页加星灵角色头部和成长反馈。
4. 信箱改树洞/手账系统。
5. universe 枢纽改地图；`wheel.vue` 不动。
6. consult 改观星台手账。

### P2：角色资产

如果没有正式插画，先用 CSS/简化 SVG 做临时星灵，不要再走纯符号。

后续需要真正出圈，必须补：

- 10 个星灵主形象。
- 10 个小动作。
- 10 个住所/地形。
- 首页森屿基础插画。

## 8. 新 demo 的设计要求

下一版 demo 不要再做暗色诗性页，而要满足：

- 第一眼有一个可爱的、非人类的星灵伙伴。
- 画面整体明亮柔和，不压抑。
- 有“小世界会生长”的暗示。
- 有森林/星屿/云雾/星尘，而不是房间/灯/玻璃卡片。
- 页面能明显看出是 App 首页，不只是概念海报。
- 功能入口藏在世界里，但仍然清楚可点。
- 保持现代质感，不能变低龄儿童游戏。

## 10. 最终结论

本次视觉重构方向改为：

# 星灵森屿 · 会长大的内在伙伴宇宙

但执行上要以 `frontend/xingling_garden_app_prototype_v2(1)(2).html` 的清爽层级为基准：

- 每屏只保留一个主视觉焦点，不同时堆伙伴、地图、入口、装饰。
- 首页优先“问候 + 今日星灵 + 一句话陪伴 + 一个行动按钮 + 一张内在天气卡”。
- 底部导航承载入口，不把所有功能再塞进首页。
- 装饰只服务氛围，不能抢信息层级。
- 深色页面只用于对话 / 宇宙 / 我的等沉浸场景，首页保持明亮、安静、有呼吸感。

一句话执行准则：

> **不要再做“疗愈风页面”，要做一个用户愿意每天回来看看的内在小世界；但这个小世界必须干净、克制、像 V2 一样有主次。**

后续所有视觉、动效、文案、组件都围绕这个目标展开。
