# 星灵花园 · 首页设计方案（Homepage Design Spec）

> 状态：**设计定稿，待实现**（2026-08-10）
> 性质：产品/视觉/交互完整规格。可单独拿给任意 AI 当上下文（生成素材 / 出实现方案）。
> 配套：`docs/spirit_ai_prompts.md`（10 星灵立绘生成 prompt）· `frontend/prototype_home.html`（P0 氛围原型）· `docs/gap_checklist.md`（落地总账）

---

## 1. 产品概念

**一座有天气、有时间、有来客的花园。**

- **有天气**：昼夜自动切换（按盘主本地时间）——白天蓝天白云，夜晚星空点点
- **有时间**：问候随时间段变、今日月相与行运随日子变
- **有来客**：星灵在花园里等你，点它就能说话；今日行运星灵会"来访"微光

**设计 reframe（硬线内）**：选星灵 = **选"此刻想被谁接住"**，不是选"我是谁"。10 颗星合起来是完整一个人内心的十个声音，选择页绝不贴人格标签。

**治愈感来源**：光 + 色 + 慢速动效 + 安静（不是插画本身）。P0 纯 CSS 已达 80% 氛围，插画是加分项。

## 2. 信息架构

```
底部 tab（3 个）：
  🏡 花园        ✉️ 信箱（内部两小tab：来信 | 日记）      🪐 我的宇宙

花园右上角：头像（进设置/档案）——不放信箱（信箱已入 tab）
信箱未读红点 / 我的宇宙待验证红点：沿用现有机制
```

| 决策点 | 拍板 |
|---|---|
| 右上角 | 信箱去掉，改头像（设置） |
| 信箱 | 入底部 tab，内部「来信｜日记」并排两小 tab |
| 日记 | = 信箱里的来信式日记（keepsake），不另建页 |
| 聊天 | 不占 tab，入口 = 点花园里的星灵 |
| 聊天模式 | 默认随心聊（陪伴轨道），星灵人格=用户链接的星灵 |

## 4. 设计 tokens（昼夜双生，靠"绿"和"金"锁品牌）

| Token | 白天 | 夜晚 | 说明 |
|---|---|---|---|
| 主色族：绿 | 清新草绿（草地 `#A8D67A→#4E7F2E`） | 深林绿（天空底 `#0B1E38→#0D1F1A`） | 锁"花园"品牌 |
| 辅助色：金 | `#FFD98E` / `#FFE082` | 同左 | 星灵光晕/灵魂碎片/亮点全用它 |
| 天空 | 天蓝→白 `#7EC8F7→#EAF7FF` | 深蓝黑→深绿 | 昼暖阳 / 夜星空+月相月亮 |
| 字体 | 圆润黑体族（HarmonyOS Sans / MiSans 优先） | 同左 | 标题字距放宽 |
| 圆角 | 卡片 24-32rpx，chip 无限圆角 | 同左 | 柔和 |
| 动效 | 白云漂移 60-90s；蝴蝶 16-22s | 星星闪烁 4s；萤火虫 5s | 昼夜渐变过渡 ~1.2s |

**昼夜切换**：真实自动切换（盘主本地时间）；P0 原型用按钮演示。

## 5. 逐区规格

### 5.1 天空层 · 问候与提示语

- 问候 = 时间段（早安/午安/晚安，后端 `_time_of_day_greeting` 已有）+ 季节（后端按日期出，前端色温/emoji）
- **提示语 = 今日主行运驱动**（Domain 出事实，文案自由）：
  - 主行运强时 → 模板库：`rule_id(行星×相位×宫位)` 组合出句，如「今日水星在你的 10宫·事业搭了座桥，适合推进那件悬着的事」
  - 主行运弱时 → 兜底心情文案库（30-60 条，按日期取模）
  - 全确定性、免 LLM、硬线内（占星事实全由 Domain）

### 5.2 今日星象卡（月相 + 月亮落座 + Domain 建议）

- 内容：`今日 · {月相8相} · 月亮落{星座}` + 一句建议
- 数据：`moon_phase_angle(jd)` → 8 相（新月/娥眉/上弦/盈凸/满月/亏凸/下弦/残月）；月亮黄经 → 落座（均已有算法，未出前台）
- **建议由 Domain 确定性规则出**（硬线）：新月=许愿播种｜上弦=推进做决定｜满月=看见释放｜下弦=整理休整
- 视觉：SVG 月牙（随相位角绘制）

### 5.3 花园层 · 环境

- 草地多层渐变 + 小花（emoji 占位 → P1 透明 PNG）+ 蝴蝶（昼）/ 萤火虫（夜）
- 行运微亮：`Daily` 已产出"今日行运走到 X 宫"，花园对应生活领域一小丛花微亮（本期可选，属"格子反转+行运微亮"活态层）

### 5.4 星灵接引（本页核心）

**花园中央 = 用户链接的星灵（方案 A 用户主权）**

- 视觉：行星 PNG/立绘 + 金色光晕 + 呼吸浮动（4.5s）+ 光尘粒子
- 接引语：来自 persona 疗愈名 + 一句人设台词（「月亮 · 想被抱抱的我」「你回来了，今天想靠一下吗？」）——不靠 LLM 现编
- 动作：点它 → 直接进聊天（带上今日语境）

**今日来访星灵（旁边一抹微光）**

- 机制：= 今日最显著行运行星（与每日来信 sender 同源，信与花园互相印证）
- 视觉：对应行星色小光球 + 呼吸（3.6s）+ 「今日它想见你 · 换一位？」
- 动作：点它 → 打开星灵选择页（半屏弹层）

**入口汇总**：点中央星灵=聊天；点来访微光 / 星灵弹层里「换一位」= 选择页。

## 6. 星灵选择页（半屏弹层）

```
┌────────────────────────────────────┐
│ 花园 · 想让谁接住你？                │  ← 顶部语境文案
│  ✨ 今日推荐（今天它们想见你）        │
│  ┌──┐  ┌──┐  ┌──┐                  │
│  │月亮│  │水星│  │木星│  ← 3 位大卡  │
│  │想被抱抱│ │想说话│ │想飞│           │
│  │[今日行运]│[最近常聊]│[今日行运]│    │  ← 可解释推荐理由
│  └──┘  └──┘  └──┘                  │
│  ── 全部星灵 ──                      │  ← 10 位列表，当前链接高亮 ✓
│  ☀ 太阳 · 想被看见的我 · 写给…        │
│  ☾ 月亮 · 想被抱抱的我 · 写给… ✓     │
│  …                                  │
└────────────────────────────────────┘
```

### 6.1 推荐三轴（Domain 出，可解释）

| 轴 | 信号 | 数据 |
|---|---|---|
| ① 今日行运活跃 | 今日哪些星在动（相位权重） | ✅ Daily 已产 |
| ② 近期共振 | 34 子类·行星区深度分 | ✅ 已存 |
| ③ 长期课题 | 本命相位/落宫 → 每星课题端 | ❌ 设计定，代码未实现（留位） |

评分 `①×0.5 + ②×0.3 + ③×0.2`（③未实现时权重并入前两轴），取 top 3。每位带一句推荐理由（可追溯）。

### 6.2 星灵介绍卡（= 用户换星灵的理由来源）

| 字段 | 示例（月亮） | 数据 |
|---|---|---|
| 行星图标 | ☾ + PNG/立绘 | ✅ |
| 疗愈名 | 想被抱抱的我 | ✅ HEALING_NAMES |
| 写给 | 写给那个强撑了很久、总说"我没事"的自己 | ❌ 需补 `spirit_intro` |
| 常对你说 | 「你可以累，可以靠过来」 | ❌ 需补 `spirit_intro` |
| **适合什么时候选它** | 累的时候 / 想被接住的时候 | ❌ 需设计（换星灵的"为什么"） |
| 推荐理由（仅推荐位） | 今日月亮六合你的太阳 | ✅ 可生成 |

### 6.3 选择时机（氛围优先）

- 首次：首页花园"空" → 中央一句「花园在等一位星灵，先选一位陪你吧」→ 点开选择页
- 日常：点星灵 → 弹「和 TA 聊聊 / 换一位」；点今日来访微光 → 「它今天想见你，要换吗？」
- 选完：存 `preferred_persona` → **agent 真正读取**（治掉 gap_checklist「存了不读」死穴）→ 花园中央换人

## 8. 后端要加的字段（/garden 扩展，向后兼容，全是 Domain 确定性产出）

|---|---|

## 9. 验收清单

- [ ] 昼夜自动切换（本地时间），渐变过渡自然
- [ ] 白云漂移 / 蝴蝶(昼) / 萤火虫(夜) 动效密度适中，`prefers-reduced-motion` 覆盖
- [ ] 花园中央 = 用户链接星灵；今日来访微光 = 行运主导星（与来信 sender 一致）
- [ ] 首次进花园见"空花园"引导 → 选星灵 → 花园换人
- [ ] 选择页 = 推荐 3 位（带理由）+ 全部 10 位（介绍卡），半屏弹层
- [ ] `preferred_persona` 被 agent 读取生效（聊天用所选星灵）
- [ ] 提示语 = 行运驱动，弱行运日兜底文案库
- [ ] 今日星象卡 = 月相 + 月亮落座 + Domain 建议
- [ ] 底部 tab：花园 | 信箱(来信\|日记) | 我的宇宙；右上头像
- [ ] 全页面（chat/mailbox/universe）跟随 light/dark 主题 token
- [ ] 无插画资产时整体不破（CSS 兜底），星灵立绘就位后无缝升级
